## 手順1　応答メッセージをオンにする

テキストボタン（B・C・E・F）は「キーワード応答」で返信します。先にオンにしておかないと押しても反応しません。

1. 管理画面 右上「設定」→「応答設定」
2. **応答メッセージ：オン**（チャットはオンのままで可）

## 手順2　キーワード応答を4つ作る

各メッセージで **キーワード** を設定し、下の本文を貼り付けて保存・公開（オン）にします。
キーワードは**リッチメニューのテキストと完全に同じ文字**にしてください。

## 手順3　リッチメニューを作る

「ホーム」→「トークルーム管理」→「リッチメニュー」→「作成」

| 項目 | 設定 |
|---|---|
| タイトル | はるみ整体 メインメニュー |
| 表示期間 | 今日〜2030年頃まで（長めに） |
| メニューバーのテキスト | メニュー |
| メニューのデフォルト表示 | **表示する** |
| テンプレート | **大・6分割**（上3つ・下3つ） |
| 画像 | 「背景画像をアップロード」→ `richmenu_harumi_2500x1686.png` |

### アクション（A〜Fはテンプレートの左上から右下の順）

| 位置 | タイプ | 設定値 | アクションラベル |
|---|---|---|---|
| A 左上 | リンク | `https://utage-system.com/event/aZ36YSd5Fnnt/register` | WEB予約 |
| B 中上 | テキスト | `料金・メニュー` | 料金・メニュー |
| C 右上 | テキスト | `アクセス` | アクセス |
| D 左下 | リンク | `https://utage-system.com/p/gEI6unZZ17F9` | 初めての方へ |
| E 中下 | テキスト | `電話する` | 電話する |
| F 右下 | テキスト | `相談したい` | ご相談 |

最後に「保存」。表示期間に入っていれば、すぐ全員のトーク画面に表示されます。

> 既に別のリッチメニューが表示期間中の場合は、そちらを停止（または削除）してください。
> 表示期間が重なっていると、新しいメニューが表示されません。

## 手順4　動作確認

スマホのLINEでアカウントのトークを開き、6つすべてを押して次の点を確認します。

- A・D：ブラウザで予約ページ／HPが開く
- B・C・E・F：自分の発言が送られた直後に、手順2の文面が返ってくる

テキストボタンを押しても返事が来ない場合は、次のどちらかが原因です。
- 応答メッセージがオフになっている（手順1）
- キーワードがメニューのテキストと1文字でも違う（全角／半角の「・」などに注意）
